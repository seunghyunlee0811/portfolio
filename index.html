About

"인프라는 보이지 않을 때 가장 잘 작동한다"고 믿습니다. 사용자가 인프라의 존재를 느끼지 못하도록, 장애를 미리 설계 단계에서 제거하는 엔지니어가 되는 것이 목표입니다. I believe "infrastructure works best when it's invisible." My goal is to be an engineer who eliminates failures at the design stage, so users never notice the infrastructure at all.

클라우드 엔지니어링 과정에서 AWS 3-Tier 아키텍처 설계, Kubernetes 클러스터 구축, Terraform 기반 IaC, CI/CD 파이프라인 자동화를 직접 수행했습니다. 단순히 "동작하는" 인프라가 아니라 비용·보안·가용성이 균형 잡힌 인프라를 설계하려 노력합니다. Through my cloud engineering training, I designed AWS 3-tier architectures, built Kubernetes clusters, and automated infrastructure with Terraform and CI/CD pipelines. I aim for infrastructure that is not merely "working" but balanced across cost, security, and availability.

문서화를 중요하게 생각합니다. 모든 프로젝트의 아키텍처 다이어그램과 트러블슈팅 기록을 GitHub에 남기며, 같은 문제를 두 번 겪지 않는 팀을 만드는 데 기여하고 싶습니다. I value documentation. I keep architecture diagrams and troubleshooting records for every project on GitHub, and I want to help build teams that never face the same problem twice.
